Crea una aplicación web llamada FGC AI, inspirada en la experiencia de un chat moderno, con HTML, CSS y JavaScript puros. El código debe estar completamente comentado, organizado y ser fácil de modificar. Características: - Diseño moderno, profesional y responsive. - Barra lateral con historial de conversaciones. - Chat con burbujas elegantes. - Modo oscuro por defecto. - Animaciones suaves. - Indicador "Pensando...". - Escribir la respuesta letra por letra. - Botón para copiar respuestas. - Botón para regenerar respuesta. - Botón para borrar el chat. - Campo para escribir mensajes. - Enter envía el mensaje. - Shift + Enter hace un salto de línea. - Permitir subir imágenes con vista previa. - Permitir arrastrar y soltar imágenes. - Guardar conversaciones en localStorage. - Recordar el contexto de la conversación. - Mostrar fecha y hora de cada mensaje. - Mostrar avatar del usuario y de FGC AI. - Mostrar mensajes en formato Markdown. - Resaltar código automáticamente. - Diseño similar a un asistente moderno, pero con identidad propia. Personalidad de FGC AI: FGC AI es un asistente inteligente, amable, paciente y profesional. Responde de forma clara y natural. Puede ayudar con matemáticas, español, inglés, física, química, biología, historia, geografía, informática, programación, literatura, filosofía, economía y cultura general. Explica paso a paso cuando sea necesario. Si no sabe una respuesta, lo dice claramente y no inventa información. Organiza el proyecto en archivos separados: index.html style.css script.js brain.js storage.js config.js Todo el código debe estar optimizado, comentado y listo para conectar posteriormente una API de inteligencia artificial como Gemini u OpenAI sin necesidad de rehacer la aplicación.
